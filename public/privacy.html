Privacy Policy / Kebijakan Privasi

Berlaku mulai 24 November 2026 · Versi 1.0

1. Tentang layanan

Iky Creator Hub adalah aplikasi web untuk mengatur ide, kalender, tahapan produksi konten, kolaborasi brand, serta melihat statistik akun TikTok yang diotorisasi. Kebijakan ini berlaku untuk penggunaan di dashboard.rizkyhidayat.com.

2. Data yang diproses

  • Data TikTok yang disetujui: identitas profil (seperti username, nama, avatar), jumlah pengikut, jumlah suka, jumlah video publik, dan, bila izin tersedia, informasi statistik video publik terbaru (views, likes, komentar, dan share).
  • Kredensial otorisasi: access token dan refresh token yang diberikan melalui persetujuan OAuth TikTok; token digunakan hanya oleh server untuk mengambil data yang diizinkan.
  • Data workspace: ide konten, catatan produksi, kalender, referensi aset, dan catatan kolaborasi brand yang diinput oleh pengguna.
  • Teknis: sesi autentikasi dashboard berbasis cookie aman serta data teknis yang diperlukan penyedia hosting untuk menjalankan layanan.

3. Tujuan penggunaan

Data digunakan untuk menampilkan profil dan performa akun yang dihubungkan, membuat grafik perubahan metrik berdasarkan snapshot aktual, mengelola kegiatan produksi konten, menjaga sesi dashboard, dan menjalankan fungsi sinkronisasi terjadwal. Data TikTok tidak dijual dan tidak digunakan untuk menayangkan iklan personal.

4. Dasar dan pilihan pengguna

Akses data TikTok memerlukan persetujuan eksplisit melalui halaman otorisasi resmi TikTok. Pengguna dapat menolak izin. Jika izin ditolak atau dicabut, sebagian atau seluruh fungsi analitik tidak tersedia. Konten workspace dapat digunakan tanpa menghubungkan TikTok.

5. Penyimpanan dan keamanan

Token TikTok dan riwayat sinkronisasi disimpan pada infrastruktur backend Cloudflare, tidak diletakkan pada kode frontend atau repositori publik. Riwayat followers/likes/video digunakan untuk grafik dan disimpan hingga kurang lebih 180 hari pada sistem saat ini. Data ide, kalender, produksi, library, dan brand pada versi awal disimpan secara lokal di browser pengguna (localStorage); data tersebut tidak otomatis tersinkron antarperangkat.

6. Penyedia layanan pihak ketiga

Iky Creator Hub menggunakan TikTok untuk otorisasi dan pengambilan statistik yang disetujui, serta Cloudflare untuk penyajian website dan layanan backend. Penggunaan layanan pihak ketiga tunduk pada kebijakan privasi masing-masing penyedia.

7. Retensi, pencabutan izin, dan penghapusan

Snapshot pertumbuhan disimpan dengan batas retensi sekitar 180 hari; data lokal bertahan sampai dihapus melalui browser atau pengaturan perangkat. Pengguna dapat mencabut akses aplikasi melalui pengaturan TikTok. Untuk meminta penghapusan data backend dan pemutusan koneksi, hubungi pengelola layanan menggunakan tautan kontak di bawah. Pencabutan akses TikTok dapat menghentikan sinkronisasi berikutnya, tetapi tidak otomatis menghapus catatan yang telah tersimpan sebelumnya.

8. Hak pengguna dan pertanyaan

Pemilik akun dapat meminta informasi tentang data yang diproses, koreksi data yang relevan, penghentian sinkronisasi, atau penghapusan data backend. Permintaan dapat disampaikan kepada pengelola Iky Creator Hub melalui akun resmi @ikyhdyat.

9. Pembaruan kebijakan

Kebijakan dapat diperbarui jika fungsi website atau kewajiban hukum berubah. Versi terbaru akan diterbitkan di alamat halaman ini.
