# Iky Creator Hub

Dashboard pribadi content creator: Dashboard, Ide / Library, Kalender Konten, Produksi Content, dan Brand.

Deployment target: Cloudflare Workers, `npx wrangler deploy`.

Sumber data awal tersimpan pada browser (localStorage). Integrasi TikTok resmi membutuhkan OAuth dan belum diaktifkan; tidak ada statistik palsu yang diklaim sebagai data live.
